PEHLE YEH KAR LO
----------------
1. v6 wali zip apply kar lo (agar abhi tak nahi ki).
2. Migrations 087 aur 088 chal chuki hon.
3. GitHub Desktop se sab commit + push kar do.
   Yeh sab se ahem qadam hai. Aage se git hi tumhara safety net hai —
   kuch ghalat lage to wapas ja sako.


SETUP
-----
1. claude.com/download se Claude Desktop install karo.
2. App kholo, upar beech mein "Code" tab par click karo.
3. Apna project folder chuno (jafson-erp).
4. Manual mode ON rehne do (default yehi hai).
   Is mode mein Claude pehle dikhata hai kya badlega — tum Accept ya
   Reject karte ho. File tab tak nahi badalti jab tak tum haan na kaho.
   Yaani wahi review jo abhi zip khol kar karte ho, bas bina zip ke.
